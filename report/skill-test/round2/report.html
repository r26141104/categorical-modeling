影響學生及格的因素：二元 logistic 迴歸分析

結論摘要

本分析以二元 logistic 迴歸（§4）探討讀書時間（studytime）、被當次數（failures）、想不想讀大學（higher）與性別（sex）對葡萄牙文科是否及格的影響，共 649 位學生（及格 549 人）。四個變數合起來有顯著關聯（LR = 96.82，df = 4，P < 0.001），AUC = 0.799，區分能力相當不錯。

在其他變數固定時，被當次數的影響最大：每多被當一次，及格勝算乘以 0.358（95% CI 0.253 – 0.495），預測及格機率從被當 0 次的 0.917 降到 3 次的 0.335。想讀大學的學生及格勝算是不想讀者的 3.766 倍（95% CI 2.040 – 6.877），預測機率為 0.898 對 0.699。讀書時間每多一級，及格勝算乘以 1.450（95% CI 1.050 – 2.046，LR 檢定 P = 0.024）。性別沒有顯著影響（LR 檢定 P = 0.510）。

模型比較顯示，把被當次數當成類別的模型明顯優於當數值分數的模型（LR = 9.53，df = 2，P = 0.009；AIC 465.44 對 470.97），代表「每多被當一次效果相同」的等距假設不成立，上述 0.358 的單一勝算比是簡化後的結果。此外，這是觀察資料，所見為關聯而非因果。
