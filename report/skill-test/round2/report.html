影響學生及格的因素：二元 logistic 迴歸分析

結論摘要

本分析以二元 logistic 迴歸（§4）探討讀書時間（studytime）、被當次數（failures）、想不想讀大學（higher）與性別（sex）對葡萄牙文科是否及格的影響，共 649 位學生（及格 549 人）。最初的模型 A 把 failures 當數值分數，但模型比較顯示把 failures 當類別的模型 B 明顯較好（LR = 9.53，df = 2，P = 0.009；AIC 465.44 對 470.97），代表「每多被當一次效果相同」的等距假設不成立，因此以模型 B 為最終模型。

模型 B 中，四個變數合起來有顯著關聯（LR = 106.35，df = 6，P < 0.001），AUC = 0.800。在其他變數固定時，被當次數影響最大（LR = 49.04，df = 3，P < 0.001），而且主要是「有沒有被當過」的差別：相對於被當 0 次，被當 1、2、3 次的及格勝算比分別為 0.164、0.158、0.099，預測及格機率從 0.927 降到 0.674、0.666、0.555。被當 2 次和 3 次各只有 16 人和 14 人，信賴區間很寬，1 到 3 次之間的高低順序並不明確。

想讀大學的學生及格勝算是不想讀者的 3.500 倍（95% CI 1.872 – 6.475），預測機率 0.927 對 0.783。讀書時間每多一級，及格勝算乘以 1.400（95% CI 1.011 – 1.980，LR 檢定 P = 0.043），證據較邊緣。性別沒有顯著影響（LR 檢定 P = 0.358）。這是觀察資料，所見為關聯而非因果。
