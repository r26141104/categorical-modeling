## 1. 二元 logistic 迴歸（A，§4.1–4.6、§5.1–5.3）

### 1.1 模型（§4.1）

$Y_i \sim \text{Bernoulli}(\pi_i)$ 彼此獨立，

$$\text{logit}(\pi_i) = \alpha + \beta x_i, \qquad \pi(x) = \frac{e^{\alpha+\beta x}}{1+e^{\alpha+\beta x}} .$$

屬於廣義線性模型（GLM，§3.1）：隨機成分為 Bernoulli、系統成分為 $\alpha+\beta x$、連結函數為 logit。

### 1.2 假設

1. 觀察值彼此獨立（§1.1.3）
2. 給定 $x$，$Y$ 服從 Bernoulli 分配
3. logit 是解釋變數的線性函數
4. 推論採大樣本近似；樣本數相對參數個數要夠大（§5.1.1）

### 1.3 參數的意義（§4.1.3–4.1.4）

- $x$ 增加 1，勝算乘以 $e^{\beta}$
- 曲線斜率 $\beta\pi(x)[1-\pi(x)]$，在 $\pi = 0.5$ 時最大（$\beta/4$）
- $\pi = 0.5$ 發生在 $x = -\alpha/\beta$（median effective level）

### 1.4 估計（§4.2.1、§3.5）

最大概似法。對數概似

$$\ell(\alpha,\beta) = \sum_i \big[y_i(\alpha+\beta x_i) - \log(1+e^{\alpha+\beta x_i})\big]$$

概似方程式 $\sum_i (y_i - \pi_i) = 0$、$\sum_i x_i(y_i - \pi_i) = 0$ 沒有封閉解，用 Newton–Raphson（Fisher scoring／IRLS）求解；$SE$ 來自訊息矩陣的反矩陣。

### 1.5 推論（§4.2.2–4.2.4）

- Wald：$z = \hat\beta/SE$，$z^2 \sim \chi^2_1$
- 概似比：$LR = -2(\ell_0 - \ell_1) = D_0 - D_1 \sim \chi^2_1$
- Score 檢定
- 小樣本或效果很強時 Wald 檢定較不可靠，優先用 LR 檢定與 profile likelihood 信賴區間

### 1.6 類別型與多個解釋變數（§4.3–4.4）

- $c$ 類的類別變數用 $c-1$ 個指標變數；係數是「該類 vs 參考類」的對數勝算比
- 多個解釋變數時，$e^{\beta_j}$ 是**其他變數固定**的勝算比
- 變數整體效果：LR 檢定比較有、沒有該變數的模型，$df$ = 拿掉的參數個數
- 有序類別可給分數當數值（1 個參數，假設等距效果）或當類別（不做此假設）

### 1.7 模型檢查

- **適合度（§5.2）**：解釋變數全為類別、資料可分組時，用 deviance $G^2$ 或 Pearson $X^2$；有連續解釋變數時 deviance 不能當適合度檢定（§5.2.3），改和較複雜的模型做 LR 比較
- **預測能力（§4.6）**：ROC 曲線與 AUC（concordance index）
- **完全分離（§5.3）**：某個 $x$ 值能完美區分 0 與 1 時 $\hat\beta = \infty$，軟體印出很大的係數與 SE，Wald 檢定無效；改看 LR 檢定與 profile likelihood 區間；可考慮 Firth 懲罰概似法（§5.4，B 級）
- **樣本數（§5.1.1）**：較少的那一類結果，每個參數約 10 個以上

### 1.8 常見誤解

- 勝算比不是機率的倍數（只有 $\pi$ 很小時才接近相對風險，§2.3.4）
- 觀察資料的關聯不代表因果

## 2. Baseline-category logit（A，§6.1）

### 2.1 模型

$J$ 類名目結果、第 $J$ 類為基準：

$$\log\frac{\pi_j(x)}{\pi_J(x)} = \alpha_j + \beta_j x, \quad j = 1,\dots,J-1, \qquad \pi_j(x) = \frac{e^{\alpha_j+\beta_jx}}{1+\sum_{h=1}^{J-1}e^{\alpha_h+\beta_hx}} .$$

### 2.2 假設

1. 觀察值彼此獨立；給定 $x$，$Y$ 服從多項分配
2. 每條方程式的 logit 是 $x$ 的線性函數
3. 類別沒有順序（有順序時用累積 logit 才能利用順序資訊）

### 2.3 推論與解釋（§6.1.2–6.1.4）

- 變數整體效果：$H_0: \beta_1 = \cdots = \beta_{J-1} = 0$，$LR \sim \chi^2_{J-1}$
- $e^{\beta_j}$：「第 $j$ 類 vs 基準類別」的勝算比
- 任兩類 $a, b$：$\log(\pi_a/\pi_b) = (\alpha_a-\alpha_b) + (\beta_a-\beta_b)x$
- 換基準類別不影響配適與預測機率
- 用各類別的預測機率描述整體樣貌（§6.1.3）

## 3. 累積 logit／比例勝算模型（A，§6.2–6.3）

### 3.1 模型

$$\text{logit}\,P(Y \le j \mid x) = \alpha_j + \beta x, \quad j = 1,\dots,J-1, \qquad \alpha_1 < \alpha_2 < \cdots < \alpha_{J-1} .$$

- 所有切點共用 $\beta$（比例勝算）：$x$ 增加 1，任何切點的累積勝算乘以 $e^{\beta}$；「落在較高類別」的勝算乘以 $e^{-\beta}$
- 參數化注意：statsmodels 的 `OrderedModel` 與 `MASS::polr` 為 $\theta_j - \beta x$，正負號和課本相反

### 3.2 假設

1. 觀察值彼此獨立；給定 $x$，$Y$ 服從多項分配
2. 結果類別有自然順序
3. 比例勝算：$x$ 對每個累積 logit 的效果相同

### 3.3 推論（§6.2.2）

$H_0: \beta = 0$，$LR \sim \chi^2_1$。每個解釋變數只有 1 個參數，比 baseline-category logit 精簡，有趨勢時檢定力較高。

### 3.4 比例勝算假設的檢查（§6.3.2，A/B）

和每個切點各有 $\beta_j$ 的一般模型做 LR 比較，$df = (J-2) \times p$。假設被拒絕時：

- 單一勝算比可能過度簡化（例如某組只是分布較分散，而不是整體往上或往下移）
- 可分開描述各切點的效果，或使用非比例勝算模型
- 樣本很大時，即使偏離很小也可能拒絕，要搭配預測機率判斷實際差異

### 3.5 不建議的做法（§6.2）

- 把有序結果壓成兩類再做二元 logistic：損失資訊，結論隨切點改變
- 忽略順序，改用 baseline-category logit：參數多、看不出趨勢

## 4. 比較兩個模型（A，§4.3、§5.1–5.2）

### 4.1 巢狀模型的概似比檢定（§5.2）

- 模型 $M_0$ 是 $M_1$ 的特例（把 $M_1$ 的某些參數設為 0 或加上限制就得到 $M_0$）時，稱為巢狀（nested）
- 統計量 $LR = -2(\ell_0 - \ell_1) = G^2(M_0) - G^2(M_1)$，$H_0$（較簡單的模型就夠）下近似 $\chi^2_{df}$，$df$ = 兩個模型的參數個數差
- $P$ 小 → 多出來的參數有必要，用較複雜的模型；$P$ 不小 → 沒有證據需要較複雜的模型，依簡約原則用較簡單的模型
- 兩個模型必須使用**同一批觀察值**（缺失值要依兩個模型用到的所有變數一起排除）

### 4.2 數值分數 vs 類別（§4.3）

- 有序的數字代碼當數值分數：1 個參數，假設「每增加一級，對數勝算改變相同的量」（等距、線性）
- 當類別：$c-1$ 個參數，不做等距假設
- 數值分數模型是類別模型的特例（類別模型的係數剛好落在一條直線上），所以兩者是巢狀，可用 LR 檢定比較，$df = (c-1) - 1$
- 類別模型明顯較好時，代表等距假設不成立，例如效果集中在某兩級之間

### 4.3 AIC（§5.1）

- $AIC = -2\ell + 2k$（$k$ = 參數個數），兼顧配適度與簡約，**越小越好**
- 可比較不是巢狀的模型（例如兩組不同的解釋變數），但沒有 $P$ 值，只是相對比較
- 兩個模型必須使用同一份資料、同一個結果變數

### 4.4 注意事項

- 一次比較很多模型、挑 $P$ 最小的，會高估效果（多重比較），應依研究問題事先決定要比較哪些模型
- 「不顯著」不代表變數沒有效果，只代表這份資料沒有足夠證據
